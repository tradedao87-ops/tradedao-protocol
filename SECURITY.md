# Security Policy

TradeDAO prioritizes the security, integrity, and resilience of its quantitative infrastructure, smart contracts, and telemetry endpoints.

---

## Reporting a Vulnerability

If you identify a potential security vulnerability within TradeDAO smart contracts, public APIs, or SDK libraries, **please do not disclose it publicly**.

Please report security issues directly to the security engineering team:

- **Email:** `security@tradedao.ai`
- **PGP Fingerprint:** `4B21 8A19 C2E0 9F31 D008 192A 55D3 9832 6F99`
- **Telegram (Urgent):** Contact the verified protocol admins via official channels.

We ask that you include:
1. Clear description of the vulnerability and attack vector.
2. Step-by-step reproduction steps or proof-of-concept (PoC).
3. Assessment of impact on fund safety, order execution, or protocol availability.

---

## Bug Bounty Program

TradeDAO operates an institutional bug bounty rewarding white-hat researchers for responsible disclosures:

| Severity | Scope | Maximum Bounty |
|---|---|---|
| **Critical** | Direct theft of user funds, smart contract drain, or execution tampering | Up to **$50,000 USDT** |
| **High** | Temporary protocol freeze, unauthorized dividend claim, or unauthenticated admin escalation | Up to **$15,000 USDT** |
| **Medium** | API rate limit bypass, telemetry denial-of-service, or unverified trade spoofing | Up to **$5,000 USDT** |
| **Low** | Non-sensitive information disclosure or minor logic discrepancies | Up to **$1,000 USDT** |

---

## Out of Scope
- Denial of Service (DDoS) attacks against public cloud frontend infrastructure.
- Social engineering or phishing targeting protocol community members.
- Issues related to third-party centralized exchange API outages.
